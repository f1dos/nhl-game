# Разработка NHL Manager 26

Стабильная ветка проекта — `main`. Не разрабатывайте новые функции напрямую в
ней. Создавайте ветку от актуального `main`, например:

```bash
git switch main
git pull --ff-only
git switch -c feature/trade-center
```

Используйте префиксы `feature/`, `fix/`, `balance/` и `release/`. Один набор
связанных изменений должен находиться в одной ветке. Перед pull request
выполните:

```bash
npm test
npm run build
```

В описании pull request укажите изменённое поведение, способ проверки и
известные ограничения. После слияния удалите рабочую ветку.
