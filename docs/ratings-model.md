# NHL statistics rating model v1

Player and team OVR values are derived game ratings, not official NHL or EA Sports
ratings. The goal is a reproducible strength hierarchy grounded in NHL data rather
than random roster generation.

## Sources and snapshot

- NHL roster API, current 2026/27 rosters
- NHL Stats REST summaries for the 2026/27 and 2025/26 regular seasons
- NHL standings snapshot for team results, fetched 2026-11-14

`npm run sync:nhl` downloads all inputs, validates the roster and regenerates the
checked-in data module. The generator fails if Connor McDavid is not the unique
97-OVR anchor or Carolina is not the #1 / 92-OVR team in this snapshot.

## Player method

Current-season games carry full weight and the previous season carries 32% weight.
A prior is added to games, points, goals and save volume so that one excellent game
cannot make a call-up the league's best player. Skater scores combine scoring rate,
goal rate, ice time and plus/minus impact. Defensemen use a separate balance with
more weight on ice time and impact. Goaltenders combine regressed save percentage
and win rate.

Forwards, defensemen and goaltenders are ranked separately and mapped onto controlled
60–96, 60–94 and 60–93 ranges. Connor McDavid is the 97-OVR elite anchor. The target
OVR is applied back to the 30 gameplay attributes, so the match engine and annual
development recalculate the same value rather than showing a decorative number.

## Team method

Teams are ordered by current point percentage, with goal differential as the first
tiebreak. Ratings map from 92 for rank 1 to 75 for rank 32. The static snapshot rating
is visible in club selection and contributes a modest strength term to possession in
the match engine. Career standings still begin at 0–0 and are generated by gameplay.

## Limitations

This is an early-season snapshot and will change when the sync script is rerun. It
does not yet use public tracking data, quality of competition, isolated xG impact,
contract value or playoff performance. Plus/minus is deliberately low-weight. The
model is transparent and testable, but it is not a claim of an official rating.
