# Match characters

The live match and ModelLab construct skaters and goalies with `src/ui/skinnedRig.ts`.
The same geometry, uniform materials and pose solver are exported to `skater-match.glb`
and `goalie-match.glb` by `scripts/export-characters.mjs` against a running Vite dev server.

All three face meshes derive from MakeHuman's CC0 HM08 body. The Blender conversion
in `scripts/build-face.py` extracts the head, simplifies each camera level and writes
`src/assets/hm08-head.json`. Runtime morphs vary the jaw, cheekbones, nose and eye
spacing. [Source mesh and CC0 dedication](https://github.com/makehumancommunity/makehuman/blob/master/makehuman/data/3dobjs/base.obj)

## Earlier Blender studies

Original procedural modelling studies generated by `scripts/build-hockey-assets.py`
with Blender 4.3.2. Both editable Blender sources and exported GLB files are included.
No third-party character models or textures were used.

These assets are **not final accepted player models** and are no longer loaded by
the match renderer. They establish reproducible mesh, equipment, skeleton and animation
export. Each equipment component currently uses rigid bone weights. The skating
study tests two leg channels; it is not a finished hockey animation.

Second iteration adds curved visor, chin straps, helmet vents, boot laces,
segmented gloves, uniform trim, demonstration lettering, goalie cage/catcher/blocker
and sewn pad panels. Front three-quarter review renders are included. Lettering
is currently geometry with placeholder identities, not career player textures.

Outstanding: anatomical refinement, joint deformation and blended weights,
career jersey name/number textures, hand IK, skating contact,
full animation library, LOD, compression, in-app demonstration and visual review.
No performance target or Football Manager quality parity has been verified.

Regenerate from the repository root:

```
blender --background --python scripts/build-hockey-assets.py
```

Export currently uses uncompressed glTF because this environment lacks the Blender
Draco exporter library. This does not prevent exporting valid GLB files.

## Editable match skater

Open `match-skater.blend` for the posed skater, packed texture maps and studio camera. Import `match-skater-parts.glb` into another DCC for 18 separately editable meshes bound to one 28-joint armature. The export has 24,693 triangles and nine animation clips. The head uses the HM08 source credited above. The body is covered by the uniform. The face is an identity variation and is not a portrait scan.

The match and ModelLab load the Blender sweater and skate libraries into the same rig. Team colours, name and number come from the career. The asset merger retains the existing player identity and does not add a draw call per lace. The far camera uses the 613-triangle sweater cage and simplified boots. The other sweater levels use 2,149 and 6,758 triangles.

To reproduce the character, run from the repository root:

1. Run `blender -b -P scripts/build-sweater.py`, `blender -b -P scripts/build-skate.py` and `blender -b -P scripts/build-headgear.py`.
2. Run the Vite development server and `node scripts/export-characters.mjs http://localhost:5173` with Playwright and Chromium available.
3. In Blender, execute `scripts/assemble-match-skater.py` with `project_root` set to the repository. It creates a separate studio scene and exports the editable character. The final review used Blender MCP's `get_scene_info`, `execute_blender_code` and `look`.
